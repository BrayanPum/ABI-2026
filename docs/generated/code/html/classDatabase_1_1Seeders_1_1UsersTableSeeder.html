Detailed Description

Seeder for populating the users table from a CSV file.

This seeder reads user data from a CSV file and inserts it into the database. Passwords are securely hashed using Laravel's Hash facade before insertion.

The CSV file is expected to have a header row followed by data rows. Required fields: email, state, role, password.
